Research demo · multi-agent trip planning

TravelMate-R: solver-certified, weather-robust itineraries

An LLM ranks real places pulled from open data. An exact solver builds the days, a TravelPlanner-style critic bank checks every plan, and each rainy-season day carries an indoor Plan B.

Solver-grounded day planning

Logic-based Benders decomposition: a MILP assigns places to days, an exact minute-by-minute day verifier adds no-good cuts, and the loop ends with an optimality certificate.

Critic bank from TravelPlanner

TravelPlanner's commonsense/hard constraint evaluator, ported to day trips (10 constraints). It is used both to score plans and to back-prompt the LLM in LLM-Modulo fashion.

Weather-robust planning

Wet-day probability from 10 years of rainfall (IMD 2.5 mm rule). The solver maximises expected utility and adds an indoor Plan B per day. Benchmarks so far assume the weather is fixed.

  T --> K["Research LLM
ranks place IDs"]
  T --> W["Wet-day probability
per day"]
  K --> M["Benders master
MILP (HiGHS)"]
  W --> M
  M --> V["Exact day verifier"]
  V -- "infeasible: no-good cut" --> M
  V --> B["Plan B per day
(indoor sub-MILP)"]
  B --> C["Critic bank
10 constraints"]
  C --> P["Certified plan"]

The LLM never schedules anything. It proposes and ranks candidate IDs that came from tools. Everything after that is exact optimisation and verification.

Reproduce

pip install -r requirements.txt
python -m research.snapshot                 # freeze tool outputs for the 40 eval cases
python -m research.experiment               # solver + greedy systems (no LLM)
python -m research.experiment --llm --provider nvidia
python -m research.report                   # research/results/report.{md,json}
STATELESS=true PLANNER=robust uvicorn app.main:app   # live app, no database
